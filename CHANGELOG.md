# Changelog

## v3.5 (2026-09-29)
- Candidates are identified by the name inside their documents, not the file
  name. Files that can't be matched are listed as "Unmatched files".
- New "Files" column in the summary table, with exact file names.
- The name rule no longer contradicts itself: names identify candidates but
  never influence the evaluation.

## v3.4 (2026-09-29)
- The Wildcard tier no longer overlaps with Worth a read.
- Every report starts with "Files received: N" so a missing candidate is easy
  to spot.

## v3.0 to v3.2 (2026-09-28)
- Three evidence levels (STRONG / WEAK / NONE) with tiers tied to them.
- Never drop a candidate silently; list unreadable files.
- A final self-check: tiers must match grades; profile-only claims count as
  NONE; no invented facts.

## v1 to v2 (2026-09-28)
- First versions: work-style spectra, Wildcard tier, protection against hidden
  instructions, verbatim quotes as evidence.
