# AI CV Screening Kit

A free, copy-paste prompt that turns the AI tool you already use into a
first-pass reader of CVs and cover letters: one that looks for evidence and
potential, not keyword counts.

It never rejects anyone. It tells you who deserves your time first, and why,
with the questions to ask on the first call.

Written about in: [LinkedIn Article](https://www.linkedin.com/pulse/your-ai-screener-reads-cvs-like-keyword-filter-doesnt-mickael-pic-0gghc)

## What's in here

| Folder / file | What it is |
| --- | --- |
| [`starter-folder/`](starter-folder/) | Copy this for each job posting. It holds the two files you need. |
| [`starter-folder/Instructions.txt`](starter-folder/Instructions.txt) | The prompt. Use it as is. |
| [`starter-folder/JobDescription.txt`](starter-folder/JobDescription.txt) | A template: paste your posting, then fill in the three screening lines. |
| [`test-kit/`](test-kit/) | Five fictional candidates built as traps, to test the prompt with your own AI tool before using it on real people. |
| [`CHANGELOG.md`](CHANGELOG.md) | What changed in each version of the prompt. |

## How to use it

1. Copy `starter-folder/` once per job posting.
2. Paste the posting into `JobDescription.txt` and fill in the three screening
   lines (dealbreakers, what success looks like, who thrives here).
3. Leave `Instructions.txt` as it is.
4. Add every CV and cover letter for that posting to the folder.
5. Give the folder, or its files, to your AI tool and type:
   *"Follow the instructions in Instructions.txt."*
6. Check that the report's "Files received: N" matches what you put in.
7. Read the shortlist. Call the Call and Wildcard candidates first, and read
   the Worth a read ones yourself. A person makes every decision.

## Before you use it on real candidates

- Use your company's business AI account, not a personal one. CVs are
  personal data.
- Check the rules where you hire. Some places require you to disclose AI use
  in job postings or to audit automated hiring tools. Ask your legal team.
- Go to the AI tool's official website yourself. Don't click the first search
  result.

## Improving it

Found a case the prompt handles badly? Open an issue with what happened (no
real candidate data, please). Improvements go into the next version and the
changelog.
